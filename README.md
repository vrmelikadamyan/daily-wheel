# Колесо дейлика

Один файл `index.html`, без сборки и зависимостей. Имена вводятся в поле справа, по одному в строке; список и название хранятся в адресе страницы (после `#`), поэтому колесо с нужными именами передаётся просто ссылкой. Последний список дополнительно запоминается в браузере.

## Запуск

Открыть `index.html` в браузере или выложить на GitHub Pages:

1. Создать репозиторий, положить в корень `index.html`.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту колесо доступно по `https://<user>.github.io/<repo>/`.

## Управление

- Клик по колесу, кнопка «Крутить» или Ctrl+Enter.
- В окне победителя кнопка «Убрать и перекрутить» снимает имя с колеса до перезагрузки страницы или кнопки «Вернуть всех»; список в поле справа при этом не меняется. Удобно, когда человека сегодня нет.
