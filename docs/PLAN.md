# План: колесо дейлика

## 1. Цель

Своя замена wheelofnames.com для ежедневного выбора ведущего дейлика. Хостится на GitHub Pages,
настраивается проще оригинала: достаточно ввести имена, цвета раздаются сами.

## 2. Требования

### Обязательные (MVP)

| № | Требование | Критерий приёмки |
|---|-----------|------------------|
| R1 | Список имён вводится в текстовое поле, по одному в строке | Пустые строки и пробелы по краям игнорируются; колесо перерисовывается при каждом изменении |
| R2 | Каждому имени свой сектор со своим цветом | Соседние секторы (включая первый и последний) не совпадают по цвету при любом количестве имён |
| R3 | Кнопка «Крутить», клик по колесу и Ctrl+Enter запускают вращение | Во время вращения повторный запуск игнорируется |
| R4 | Результат честный: каждое имя выпадает с равной вероятностью | Выбор определяется только случайным углом, без предсказуемости; статистический тест на 300+ прогонах без явного перекоса |
| R5 | Победитель показывается крупно в окне | Имя совпадает с сектором под стрелкой |
| R6 | Список и название хранятся в URL (после `#`) и передаются ссылкой | Открытие ссылки на другом устройстве даёт то же колесо; кнопка «Скопировать ссылку» |
| R7 | Последний список запоминается в браузере | Открытие базового URL без `#` восстанавливает последнее колесо |
| R8 | Работает на GitHub Pages как статический файл без сборки | Один `index.html`, внешних скриптов нет |
| R9 | Корректно на телефоне и на проекторе/большом экране | На ширине 375px нет горизонтального скролла; на 1920px колесо не выше высоты окна |

### Желательные

| № | Требование | Критерий приёмки |
|---|-----------|------------------|
| R10 | Снять выпавшего с колеса «на сегодня» (человек отсутствует) без правки списка | Имя уходит со списка колеса, список в поле не меняется, есть «Вернуть всех»; нельзя снять до менее чем 2 имён |
| R11 | Перемешать / отсортировать список | Кнопки в панели |
| R12 | Название колеса редактируется и попадает в заголовок вкладки | |
| R13 | Тёмная тема по системной настройке | |
| R14 | Доступность: клавиатура, `prefers-reduced-motion` | Колесо крутится с клавиатуры; при reduced-motion анимация короткая, без конфетти |

### Вне скоупа

Учётные записи, серверное хранение, история победителей, веса секторов, звук, несколько колёс в одной странице.

## 3. Архитектура и решения

- **Один файл `index.html`**, vanilla JS, canvas 2D. Никаких зависимостей и сборки: проще хостить и править.
- **Источник истины для состояния: URL-hash** (`#t=<title>&n=<names>`). Hash, а не query-string, чтобы GitHub Pages не
  получал список имён в запросах и чтобы ссылка работала офлайн из файла. `localStorage` только как резервная копия.
- **Разделитель имён в hash: `|`** (имена с `|` не поддерживаются, в hash через URLSearchParams кодируется безопасно).
- **Снятые «на сегодня» имена живут только в памяти страницы** и не попадают ни в hash, ни в localStorage: перезагрузка
  возвращает полный состав. Это сознательно: завтра состав снова полный.
- **Честность выбора.** Угол остановки = текущий угол + 5–8 полных оборотов + случайный остаток `[0, 2π)`. Победитель
  вычисляется из конечного угла по геометрии секторов, а не выбирается заранее с подгонкой анимации. Остаток равномерный, поэтому
  вероятность секторов равна.
- **Цвета.** Палитра из 8 контрастных цветов по кругу; на стыке последнего и первого сектора цвет подменяется, если совпал.
- **Деплой.** GitHub Pages «Deploy from a branch», ветка `main`, корень. CI не нужен.

## 4. Структура кода (index.html)

1. `readState / parseHash / writeState / listNames` — состояние.
2. `resize / draw / colorFor / shade` — отрисовка.
3. `winnerIndex / spin / announce / removeWinner / restoreAll` — вращение и результат.
4. `confetti` — украшение.
5. `syncWheel` + обработчики — связывание UI.

### Сознательно не делаем

- Правка списка во время вращения не блокируется: колесо перерисуется, победителем станет сектор под стрелкой в момент остановки. Это ожидаемо и безопасно.
- Focus-trap в модальном окне: Esc и клик по фону закрывают окно, для двух кнопок этого достаточно.
